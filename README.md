This program simulates rolling one or multiple dice. The user can enter how many dice they want to roll, and the program generates random values for each die using Java’s Random class. For every dice roll, a visual ASCII representation of the die face (1–6) is displayed. After all dice are rolled, the program calculates and prints the total sum of all dice values. The program also validates input to ensure the number of dice is greater than zero.

Main Features of the Dice Program

1. Multiple Dice Roll Support
     The user can enter any number of dice to roll at once.

2. Realistic ASCII Dice Output
     Each roll displays a visual ASCII-art dice face (1–6), making the game fun and interactive.

3. Total Calculation
     After rolling all the dice, the program automatically calculates and displays the total score.
